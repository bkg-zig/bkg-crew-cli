title: Installation
description: Install bkgcrewcli via curl, cargo, or build from source
---

## Recommended: curl installer

The fastest way to install bkgcrewcli:

```bash
curl -fsSL https://bkgcrewcli.lol/install.sh | sh
```

This downloads the latest prebuilt binary for your platform and installs it to `~/.bkgcrewcli/bin/bkgcrewcli`. You may need to add `~/.bkgcrewcli/bin` to your PATH.

## Via crates.io

If you have Rust installed:

```bash
cargo install bkgcrewclicli
```

The crate is published as `bkgcrewclicli` but the binary is named `bkgcrewcli`.

## Build from source

```bash
git clone https://github.com/ayshptk/bkgcrewcli-cli.git
cd bkgcrewcli
cargo build --release
```

The binary will be at `target/release/bkgcrewcli`.

## Verify installation

```bash
bkgcrewcli --version
```

## Prerequisites

bkgcrewcli itself has no runtime dependencies, but you need at least one agent CLI installed:

- **Claude Code**: `npm install -g @anthropic-ai/claude-code`
- **Codex**: `npm install -g @openai/codex`
- **OpenCode**: `curl -fsSL https://opencode.ai/install | bash` (or `npm i -g opencode-ai@latest`)
- **Cursor**: installed via the Cursor IDE

Check which agents are available:

```bash
bkgcrewcli list
```
