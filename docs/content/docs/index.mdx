---
title: Was ist bkgcrewcli?
description: Ein vereinheitlichtes CLI um jeden Coding-Agenten aus einer einzigen Schnittstelle zu starten
---

**bkgcrewcli** ist ein vereinheitlichtes CLI, das vier Coding-Agenten-CLIs — Claude Code, OpenAI Codex, OpenCode oder Cursor — durch eine einzige Schnittstelle ausführt.

Es startet den gewählten Agenten als Subprozess, übersetzt dessen natives Streaming-Output in einen vereinheitlichten NDJSON-Event-Stream und gibt diesen an stdout aus. Eine Integration schreiben, und es funktioniert mit jedem unterstützten Agenten-Backend.

## Warum bkgcrewcli?

Jeder Coding-Agent hat sein eigenes CLI, seine eigenen Flags, sein eigenes Output-Format. Wenn du Tooling auf Coding-Agenten aufbaust — Orchestrierungssysteme, CI-Pipelines, Evaluation-Frameworks oder Custom UIs — müsstest du normalerweise für jeden Agenten eine separate Integration schreiben.

bkgcrewcli löst das durch:

- **Ein CLI** — `bkgcrewcli run --agent <name> --prompt "..."` funktioniert gleich, egal welchen Agenten du wählst
- **Ein Event-Format** — 7 vereinheitlichte Event-Typen (SessionStart, TextDelta, Message, ToolStart, ToolEnd, Result, Error) mit konsistenten JSON-Schemas
- **Model-Aliases** — `--model sonnet` löst zur richtigen Model-ID für den jeweiligen Agenten auf
- **Process-Safety** — Subprozess-Management mit Process-Groups, graceful Shutdown und stderr-Capture

## Unterstützte Agenten

| Agent | Binary | Provider |
|-------|--------|----------|
| [Claude Code](https://docs.anthropic.com/en/docs/claude-code) | `claude` | Anthropic |
| [OpenAI Codex](https://github.com/openai/codex) | `codex` | OpenAI |
| [OpenCode](https://opencode.ai/) | `opencode` | Multi-Provider |
| [Cursor](https://cursor.com) | `cursor-agent` | Multi-Provider |
